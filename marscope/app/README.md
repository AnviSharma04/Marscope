# MARSCOPE – Martian Exploration & Survival Companion
1. `./setup.sh` (needs Flutter SDK + Python 3)
2. `python backend/app.py`
3. `cd app && flutter run`  (emulator uses 10.0.2.2:5000; real phone: `--dart-define=API=http://<PC-IP>:5000`)
Sources: NASA Mars Trek, USGS Astrogeology, NASA Curiosity/Mount Sharp, Mars 2020 raw images. Not affiliated with NASA.
Elevations/hazards are curated approximations; do not use for real navigation.
